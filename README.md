# Duskbrace: test builds

Early test builds of **Duskbrace**, a first-person survival game. This is a work in progress, shared with friends for playtesting.

## Download

Get the latest zip from [Releases](../../releases/latest), unzip it anywhere, and run `Duskbrace.exe`. Windows only, 64-bit.

The game isn't signed yet, so Windows SmartScreen may say it "protected your PC". Click **More info**, then **Run anyway**.

## How to help

Just play it from **New Game**, without looking anything up. Afterwards, tell me:

- roughly how long you played and how far you got
- where you got stuck or didn't know what to do next
- anything that broke, looked wrong or felt bad
- your PC's graphics card, and whether it ran smoothly

Asset credits are in the game under **Credits**.
